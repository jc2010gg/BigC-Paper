# Original visual menu 0.9

`visual_menu09.json` is an importable schema 6 layout. Its four PNG images were generated by `VisualMenuCatalog` using original geometric paths and gradients, with no downloaded images, stock art, copied textures, installed fonts, or external references. The existing project MIT license applies.

The layout uses a 1920 x 1080 source raster. This is the source image quality, not detection of the player's monitor resolution. Minecraft controls its own GUI scale; visual alignment across physical client resolutions still requires client verification.

The three card actions open the existing `sequence_demo`, `roulette_demo`, and `overlay_demo` screens. The X button closes the menu. Each entire card is one nonoverlapping click area, with image and label decorations above it. Text uses Tideframe's own font rasterizer and remains separate from the source PNG images.

Preview generation (after compiling the plugin classes): compile and run `tools/MakeVisualMenuPreview.java` with the repository root argument. It exports the JSON, four source PNG images, and four 1920 x 1080 preview PNG files under `evidence/visual-menu-v09-*.png`. Those previews are raster proofs, not screenshots from Minecraft.

`VisualMenuCatalogTest` checks image count and uniqueness, valid links, action area separation, aspect ratios, grid alignment, text bounds, hover pixels, schema roundtrip, and a bake of all 53 default plus runtime demo screens against native glyph and 64 MiB pack limits.
